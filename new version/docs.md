Программа для комфортного решения квадратного уравнения с произвольными коэффициентами. 
====  
Программа имеет 2 режима работы:
---
1. **запуск тестирования программы**\
2. **задание пользователем своих коэффициентов уравнения**\
В самом начале программы пользователю предлагается выбор между этими режимами.
-В первом режиме программа автоматически запускает тесты, взятые из стороннего файла и выдает \
результат решения уравнения: либо найс, либо произошла ошибка.
-Во втором режиме программа запрашивает у пользователя коэффициенты a, b, c, и решает квадратное \
уравнение на их основе.
